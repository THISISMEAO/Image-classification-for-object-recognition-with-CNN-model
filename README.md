Built and trained MLP and CNN models for image classification on MNIST
(hand-written digit images), ORL(human face images),
and CIFAR(colored objects) datasets using PyTorch 
Implemented configurable training pipelines with adjustable hyperparameters,
 including learning rate, dropout, optimizer, batch size, and network depth 
Evaluated model performance using ROC curves, accuracy/loss visualization, and confusion matrix analysis 
Conducted comparative experiments on CNN configurations, including kernel size, pooling strategy, dropout, and optimizer selection, to analyze impacts on classification performance and gaining 73% accuracy rate in CIFAR, 99% in MNIST, and 95% in ORL
